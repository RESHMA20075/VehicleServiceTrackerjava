Vehicle Service Reminder and Maintenance Tracker

About the Project

This is a Java-based project that helps users manage vehicle service details and service reminders.

Features

- Add vehicle details
- View all vehicles
- Search vehicles by number
- Check service reminders
- Exit the application

Technology Used

- Java
- ArrayList
- Scanner

How to Run

1. Install Java JDK.
2. Download the "VehicleServiceTracker.java" file.
3. Open the terminal in the file's folder.
4. Compile the program:
   "javac VehicleServiceTracker.java"
5. Run the program:
   "java VehicleServiceTracker"
